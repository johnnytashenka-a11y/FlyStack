## FlyStack — подписки.

**FlyStack+ (99 ₽ навсегда)** — для тех, кому мало стандартной темы. Настраивай цвета панели задач, меняй расположение значков и загружай свои иконки.

**FlyStack++ (299 ₽/мес)** — встроенный AI-помощник без отдельных окон и лимита контекста памяти. Доступен в один клик прямо с панели задач.
