# FlyStack — Custom Taskbar

**Легковесный и быстрый кастомизатор панели задач для Windows, написанный на чистом C++ и Win32 API.**

</div>

---

> [!NOTE]
> ### Почему именно FlyStack?
> 
> Среди десятков утилит для кастомизации **FlyStack** выделяется подходом к производительности и визуалу:
> - **Нативная скорость.** Написан на C++ с использованием Win32 API — минимальное потребление оперативной памяти и мгновенный отклик.
> - **Гибкость из коробки.** Настраивайте внешний вид, отступы, скругления и поведение элементов панели под свой рабочий стол.
> - **Минималистичный дизайн.** Аккуратная плавающая капсула, которая органично вписывается в интерфейс системы.
> - **Ничего лишнего.** Полностью бесплатный проект с открытым исходным кодом и без рекламы.

## Установка и запуск

1. Перейдите в раздел **[Releases](../../releases)** в правой части страницы.
2. Скачайте актуальную сборку `FlyStack.exe`.
3. Запустите файл — программа работает в **portable-режиме** и не требует установки.

> [!TIP]
> При первом запуске встроенный фильтр **Windows SmartScreen** может показать предупреждение. Это стандартная реакция системы на неподписанные утилиты с открытым исходным кодом, которые напрямую работают с окнами Проводника.

## Важная информация и устранение неполадок

<details>
<summary><b>⚠️ О совместимости с урезанными сборками Windows (AtlasOS, ReviOS и др.)</b></summary>

В кастомных сборках часто вырезаны системные компоненты Проводника и UWP-службы. Из-за этого:
- Кастомный трей может отображаться или работать **некорректно**.
- В редких случаях возможен **BSOD** при обращении к отсутствующим системным API.

Стабильная работа гарантируется только на оригинальных образах Windows 10 и Windows 11.

</details>

<details>
<summary><b>🛠 Как вернуть стандартную панель задач, если она пропала (Инструкция)</b></summary>
<br>

Если после некорректного завершения работы программы стандартная панель задач не вернулась автоматически, выполните следующие шаги:

**Для Windows 11:**
1. Откройте Диспетчер задач (`Ctrl + Shift + Esc`), найдите процесс `FlyStackTaskbar.exe` и снимите задачу.
2. Нажмите `Win + R`, введите `cmd` и выполните команду:
```cmd
reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\StuckRects3" /f & taskkill /f /im explorer.exe & start explorer.exe
```

**Для Windows 10:**
1. Откройте Диспетчер задач (`Ctrl + Shift + Esc`), найдите процесс `FlyStackTaskbar.exe` и снимите задачу.
2. Нажмите `Win + R`, введите `cmd` и выполните команду:
```cmd
reg.exe add "HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32" /f /ve
```

</details>
