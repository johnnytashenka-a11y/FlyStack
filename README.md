> [!IMPORTANT]
> # FlyStack — не первый и не последний кастомизатор панели задач.
> 
> Почему из сотен таких-же можно выбрать именно FlyStack?
> 
> Гибкость настроек. Из коробки ты можешь менять почти все составляющие панели задач.
>
> Передовой дизайн. Минималистичная капсула притягает взглядом. Не так-ли?
>
> Это просто крутой проект без рекламы.

# FlyStack — всё же девелопер хочет кушать.

> [!IMPORTANT]
>
> ## FlyStack — подписки.
> 
> **FLYSTACK+ (99 ₽ навсегда)** — для тех, кому мало стандартной темы. Настраивай цвета панели задач, меняй расположение значков и загружай свои иконки.
>
> **FlYSTACK++ (299 ₽/мес)** — встроенный AI-помощник без отдельных окон и лимита контекста памяти. Доступен в один клик прямо с панели задач.
>
> В подписку FlyStack++ также входят возможности подписки FlyStack+.
