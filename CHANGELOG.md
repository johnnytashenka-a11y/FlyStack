# Changelog

## 1.0.0 — MVP

- Убрана тряска иконок при наведении: больше нет spring-преобразования `.app-item:hover`, список окон не пересобирается без изменения набора HWND.
- Вместо кастомного поиска кнопка поиска отправляет системное `Win+S`; открывается обычный поиск Windows слева.
- `Microsoft Text Input Application` (`TextInputHost.exe`/`ctfmon.exe`) исключен из списка окон и из расчета режима панели.
- Календарь открывается внутри контейнера фиксированной высоты: панель больше не исчезает снизу и не дублируется сверху.
- Добавлены нативные DWM-превью окон по наведению (≈450 мс) с заголовком и закрытием при уходе курсора.
- Исправлено «мертвое» пространство экрана без полосы и без дёрганья: размер WebView и окна больше не меняется; верхний HWND обрезается регионом по нижней полосе дока и открытой панели, поэтому остальной экран видим и получает клики.
- Подготовка к релизу: портативный `source\build.bat` через `vswhere.exe`, README, LICENSE, CHANGELOG, .gitignore, удаление устаревших копий исходников и runtime-кэша.
- Публикация исходников и документации MVP в репозитории `prowka-dev/FlyStack`.
- Очистка репозитория: удалены английский README, все изображения трея, неиспользуемые ассеты и лишние файлы vendor; остались только нужные для сборки исходники и документация.
